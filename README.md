# علووم | العروض الرسمية

مرحبًا بكم في العروض الرسمية لمنصة **علووم**، وهي منصة إماراتية للمحتوى الحي والتفاعل الرقمي وصناعة المجتمعات.

## العرض الترويجي الفاخر

يعرض قدرات علووم وتجربة المحتوى والبث المباشر والتحديات واستوديو المبدعين والمجتمعات والاقتصاد الإبداعي.

### [فتح العرض الترويجي](https://alzeerr.github.io/aloom/promo/)

## العرض التنفيذي للترخيص

يعرض رؤية المنصة ونموذج الحوكمة والسلامة والخصوصية ومسار الموافقات والتراخيص.

### [فتح العرض التنفيذي](https://alzeerr.github.io/aloom/)

## طريقة العرض

- استخدم مفاتيح الأسهم أو أزرار الشاشة للتنقل.
- اضغط `F` أو زر ملء الشاشة للعرض الرسمي.
- يعمل العرض على الهاتف والحاسوب وشاشات العرض.
- للطباعة أو الحفظ بصيغة PDF استخدم أمر الطباعة في المتصفح.

# عرض علووم التنفيذي

عرض ويب عربي كامل باتجاه صحيح من اليمين إلى اليسار، متوافق مع الهاتف والحاسوب وشاشات العرض.

## رابط العرض

https://alzeerr.github.io/aloom/

## الاستخدام

- استخدم مفاتيح الأسهم أو الأزرار للتنقل.
- اضغط `F` أو زر ملء الشاشة للعرض الرسمي.
- للطباعة أو الحفظ بصيغة PDF استخدم أمر الطباعة في المتصفح.
